# Use VibeWise in ChatGPT

1. Copy the full contents of [instructions.md](instructions.md).
2. Paste into a new ChatGPT conversation, or add it to a ChatGPT Project's instructions.
3. Describe what you want to build and attach the relevant code. Start with:
   **“Help me build a notes app and understand the design. Use defaults.”**

VibeWise asks for your approach, helps you reason through the tradeoffs, supplies
or implements the agreed code using available tools, and explains the result.

Say **“Export my VibeWise session handoff”** when finishing. Save the response and
supply it to the next chat with **“Resume VibeWise using this handoff.”** A
[handoff template](session-handoff.md) and [conversation starters](conversation-starters.md)
are included. Keep only the latest active handoff as context; retain older copies
separately if you want backups.

Controls work in plain language: Pause learning, Resume learning, Use defaults,
Skip this question, Just implement this step, and Reset my learning.

These instructions don't add repository access, execution tools, or automatic
memory. VibeWise labels supplied code and unrun checks honestly. You can configure
a custom GPT with the same instructions where your account offers that editor.

ChatGPT Projects can share instructions and attached sources across related chats;
attach or connect the source you want it to use. See [official project guidance](https://learn.chatgpt.com/docs/projects).
